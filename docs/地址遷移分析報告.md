## 4. 欄位映射邏輯

### 直接映射
| DHL 欄位 | Teamwork 欄位 | 說明 |
|---------|--------------|------|
| nickName | AddressName | 地址別名 |
| companyName | CostCenterName | 公司名稱 |
| contactName | ContactName | 聯絡人 |
| address | Address1 | 地址行1 |
| address2 | Address2 | 地址行2 |
| address3 | Address3 | 地址行3 |
| phoneNumber | Phone1 | 電話 |
| phoneCountryCode | - | 不需要 (香港統一 852) |

### 需要轉換
| DHL 欄位 | Teamwork 欄位 | 轉換邏輯 |
|---------|--------------|---------|
| city | CityId | "HONG KONG" → 根據地址判斷 2/3/5 |
| country | Countryid | "Hong Kong SAR, China" → 1 |
| - | Districtid | 需要根據地址關鍵字匹配 |
| - | Zoneid | 根據 District 映射 |

## 5. 地址解析策略

### 城市判斷 (CityId)
```python
def determine_city(address_text):
    """根據地址關鍵字判斷城市"""
    address_upper = address_text.upper()
    
    # 九龍關鍵字
    kowloon_keywords = ['KOWLOON', 'KLN', 'MONG KOK', 'TSIM SHA TSUI', 
                        'KWUN TONG', 'TAI KOK TSUI', 'SHAM SHUI PO',
                        'WONG TAI SIN', 'KAI TAK', 'LAU LI KOK']
    
    # 新界關鍵字
    nt_keywords = ['NT', 'NEW TERRITORIES', 'TUEN MUN', 'SHA TIN', 
                   'YUEN LONG', 'TSUEN WAN', 'TIN SHUI WAI', 'FANLING',
                   'SHEUNG SHUI', 'TAI PO', 'SAI KUNG', 'CLEAR WATER BAY']
    
    for kw in kowloon_keywords:
        if kw in address_upper:
            return 3  # 九龍
    
    for kw in nt_keywords:
        if kw in address_upper:
            return 5  # 新界
    
    # 預設香港島
    return 2  # 香港島
```

### 地區匹配 (DistrictId)
需要建立關鍵字到 District 的映射表，例如：
- "MONG KOK" / "旺角" → District 9
- "TSIM SHA TSUI" / "尖沙咀" → District 8, 10
- "KWUN TONG" / "觀塘" → District 21, 26, 44
- "SHA TIN" / "沙田" → District 39, 40
